# แบบประเมินทักษะการแทงเข็มหลอดเลือดดำส่วนปลาย (IV OSCE Checklist)

ใช้ประเมิน return demonstration ในวันฝึกภาคปฏิบัติของหลักสูตร IV (iv.morroo.com)
เรียบเรียงจากขั้นตอนมาตรฐานในคู่มือการพยาบาลการดูแลผู้ป่วยที่แทงและคาเข็มทางหลอดเลือดดำส่วนปลาย
(ฝ่ายการพยาบาล โรงพยาบาลศิริราช พ.ศ. 2559) — ต้องผ่าน medical review ขององค์กรผู้ใช้ก่อนนำไปประเมินจริง

---

**ชื่อผู้รับการประเมิน** ______________________ **หน่วยงาน** ____________ **วันที่** __________

**เงื่อนไขก่อนสอบ:** ☐ ผ่านบทเรียนออนไลน์ครบ 9 บท ☐ ผ่าน Post-test ≥ 80%

**อุปกรณ์สถานี:** แขนฝึกแทงเข็ม/หุ่นจำลอง, IV catheter (เบอร์ 20-24), ชุดสายให้สารน้ำ + ขวด NSS,
tourniquet, 70% alcohol/chlorhexidine, สำลี, ถุงมือสะอาด, TSM dressing, พลาสเตอร์, สติกเกอร์ระบุวันเวลา,
กระบอกฉีดยา NSS สำหรับ flush, กล่องทิ้งเข็ม

**วิธีให้คะแนน:** ✓ = ทำถูกต้องครบถ้วน / ✗ = ไม่ทำหรือทำผิด
ข้อที่มีเครื่องหมาย **[C]** เป็น critical item — **ทำผิดข้อเดียวถือว่าไม่ผ่านทั้งสถานี** ไม่ว่าคะแนนรวมเท่าใด

---

## ระยะที่ 1 — การเตรียม (Preparation)

| # | รายการประเมิน | ✓/✗ |
|---|---|---|
| 1 | ตรวจสอบคำสั่งการรักษา (ชนิด ขนาด อัตรา ความถี่ วิธีให้) ตรงกับผู้ป่วย | |
| 2 | ตรวจสอบประวัติแพ้ยา / ไอโอดีน / latex **[C]** | |
| 3 | เตรียมอุปกรณ์ครบ และตรวจสภาพ-วันหมดอายุ-ความสมบูรณ์ของห่อ sterile | |
| 4 | ล้างมือถูกต้องก่อนเริ่ม **[C]** | |
| 5 | ระบุตัวผู้ป่วยอย่างน้อย 2 แหล่ง (ถามชื่อ-สกุลให้ตอบเอง + ป้ายข้อมือ/MAR) **[C]** | |
| 6 | อธิบายเหตุผล ขั้นตอน ผลข้างเคียง และเปิดโอกาสให้ซักถาม | |

## ระยะที่ 2 — การประเมินและเลือกหลอดเลือด (Vein selection)

| # | รายการประเมิน | ✓/✗ |
|---|---|---|
| 7 | ซักถาม/ตรวจข้อห้าม: AV fistula, แขน mastectomy, แขนอ่อนแรง, หลีกเลี่ยงขาและข้อพับ **[C]** | |
| 8 | รัด tourniquet เหนือตำแหน่งแทง ~5-6 นิ้ว แน่นพอดี (ยังคลำชีพจรได้) | |
| 9 | ใช้เทคนิคช่วยให้เส้นโป่งเหมาะสม (ห้อยแขนต่ำ กำ-แบมือ เคาะเบา/ประคบอุ่น) | |
| 10 | คลำประเมินเส้นด้วยนิ้วชี้-นิ้วกลาง เลี่ยงเส้นแข็ง/มีลิ้น/แยกสองทาง/มีชีพจร | |
| 11 | เลือกเบอร์เข็มเหมาะกับผู้ป่วยและแผนการรักษา (เล็กที่สุด-สั้นที่สุดที่ตอบโจทย์) | |

## ระยะที่ 3 — เทคนิคปลอดเชื้อและการแทง (Aseptic technique & insertion)

| # | รายการประเมิน | ✓/✗ |
|---|---|---|
| 12 | สวมถุงมือสะอาดขนาดพอดี | |
| 13 | เช็ดผิวหนังวนจากในออกนอก กว้าง 2-3 นิ้ว นาน ≥ 30 วินาที **[C]** | |
| 14 | ปล่อยน้ำยาแห้งเอง — ไม่พัด ไม่เป่า ไม่สัมผัสซ้ำ **[C]** | |
| 15 | เข็มปลอดเชื้อไม่สัมผัสสิ่งใดก่อนแทง (ไม่วางพาดผิว ไม่โดนมือ) **[C]** | |
| 16 | ยึดตรึงผิวหนังให้ตึงด้วยมือข้างไม่ถนัด | |
| 17 | แทงมุม 10-30° ตามความลึกเส้น เห็น flashback แล้วลดมุม เลื่อนต่อเล็กน้อยก่อนดัน catheter | |
| 18 | ดัน catheter เข้าจนสุด — ไม่สอด stylet กลับเข้า catheter ซ้ำ **[C]** | |
| 19 | ปลดสายรัดก่อนดึง stylet ใช้นิ้วกดเหนือปลาย catheter กันเลือดย้อน | |
| 20 | ทิ้ง stylet ลงกล่องทิ้งเข็มทันที ไม่วางพัก **[C]** | |
| 21 | ต่อชุดสาย/จุก lock ข้อต่อแน่น แล้ว flush ทดสอบ — ประเมินว่าไหลลื่น ไม่บวม ไม่ฝืด | |

## ระยะที่ 4 — การยึดตรึงและปิดท้าย (Securement & completion)

| # | รายการประเมิน | ✓/✗ |
|---|---|---|
| 22 | ปิด TSM คลุมจุดแทงและ hub — พลาสเตอร์ติดที่ปีกเข็ม ไม่ทับจุดแทง | |
| 23 | ไม่ฉีกพลาสเตอร์แปะพักบนโต๊ะ/ขอบเตียงก่อนใช้ | |
| 24 | โค้งสายเป็นห่วงติดพลาสเตอร์กันแรงดึงกระชาก | |
| 25 | เขียนวันที่-เวลา-ชื่อผู้แทง ติดบนวัสดุปิดเข็ม | |
| 26 | ถอดถุงมือ ล้างมือหลังเสร็จ | |
| 27 | บอกรายการบันทึกทางการพยาบาลได้ครบ (ตำแหน่ง เบอร์ จำนวนครั้ง ผล flush การตอบสนอง) | |

## ระยะที่ 5 — คำถามสถานการณ์ (ผู้สอบถามปากเปล่า เลือก 3 ข้อ)

| # | คำถาม | คำตอบที่ต้องได้ | ✓/✗ |
|---|---|---|---|
| Q1 | แทง 2 ครั้งไม่สำเร็จ ทำอย่างไร | ส่งต่อผู้ชำนาญกว่า ไม่แทงต่อเอง ใช้เข็มใหม่เสมอ | |
| Q2 | flush แล้วมีแรงต้าน ทำอย่างไร | ห้ามดันฝืน — ถอดเข็ม เปลี่ยนตำแหน่ง | |
| Q3 | พบปวด บวม แดง คลำเส้นเป็นลำ คือ grade ใด ต้องทำอะไร | Phlebitis grade 3 — ถอดเข็ม เปลี่ยนตำแหน่ง รายงาน ประคบร้อน | |
| Q4 | KCl รั่วออกนอกเส้น ประคบอะไร | ประคบเย็น ห้ามประคบร้อน หยุดยาทันที | |
| Q5 | เปลี่ยนตำแหน่งเข็มทุกกี่ชั่วโมง / เข็มฉุกเฉินล่ะ | 96 ชม. (หรือทันทีเมื่อมีอาการ) / ฉุกเฉินไม่เกิน 48 ชม. | |
| Q6 | ต้องสอนผู้ป่วยแจ้งอะไรบ้าง | ปวด บวม แสบ ตึง เข็มหลุด วัสดุปิดเปียก/เปื้อน | |
